# Emoticons for Forge

Build every Minecraft version with `./gradlew buildAll`.

- **1.12.2:** build with `./gradlew :1.12.2:build` and test with `./gradlew :1.12.2:runClient`.
- **1.10.2:** build with `./gradlew :1.10.2:build` and test with `./gradlew :1.10.2:runClient`.
- **1.9.4:** build with `./gradlew :1.9.4:build` and test with `./gradlew :1.9.4:runClient`.
- **1.8.9:** build with `./gradlew :1.8.9:build` and test with `./gradlew :1.8.9:runClient`.
- **1.7.10:** build with `./gradlew :1.7.10:build` and test with `./gradlew :1.7.10:runClient`.
